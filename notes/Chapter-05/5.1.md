Docker — simple notes
Where a database can run: someone else runs it for you online (costs money, too much for now), or you install it yourself on your laptop (causes problems later), or you run it inside Docker (free, easy to delete and redo, same for everyone — this is what we use).
Why not install it directly on your laptop: you might get a different version than your teammates or the real server, causing weird bugs only on some computers; it keeps running in the background forever and clutters your laptop; and if it breaks, it's hard to clean up and start fresh.
What Docker does: it puts the program and everything it needs into one sealed box, so it runs the exact same way on any computer.
Simple terms:
Container — a sealed box on your computer that's actually running the program (like Postgres) right now, separate from everything else on your laptop.it runs on any machine easily without changing anything inside it.

Image — just a saved copy of "how to set this up," sitting unused on your disk. A container is what you get when you actually start that saved copy running. You can start the same saved copy many times and get many separate running boxes.

Docker Engine — the actual app on your computer that starts and stops these boxes. Docker Desktop is just this with a nice window/interface added.

Docker Hub — a website where these ready-made saved copies live; you download one the first time, then it's saved on your computer so you don't need to download it again.

Ports — since the box is sealed, your app can't reach what's inside unless you open a door between a number on your laptop and a number inside the box.


Volumes — normally, anything saved inside the box disappears if you delete it. A volume is a separate storage spot outside the box, so your real data doesn't disappear even if you delete and rebuild the box. (Most beginners lose data once by forgetting this.)
Docker Compose — instead of starting each box one by one, you write one file listing everything you need, and one command starts it all the same way every time.
Big idea: Docker lets you run your database and Redis in throwaway boxes on your laptop that are easy to delete and rebuild, work the same for everyone, and can later be swapped for a real hosted service without changing your code.
